# godot_curso1

Este repositorio contiene las capturas y notas de las prácticas (pra1..pra24) realizadas siguiendo el curso básico "Learn GDScript from Zero with Godot" (GDQuest). En la carpeta `godot curso/` están las imágenes tomadas durante cada práctica. Abajo hay un breve resumen de qué se trabajó en cada una.


## Resumen por práctica (pra1 — pra24)

Cada entrada contiene: objetivo corto y la captura asociada (si existe).

- pra1 — Introducción a Godot y primer proyecto
	- Objetivo: Familiarizarse con el editor, crear un proyecto, escena base (Node2D) y añadir un Sprite.
	- Captura: `godot curso/pra1.png`
	- Imagen: ![pra1](godot%20curso/pra1.png)

- pra2 — Movimiento básico e Input
	- Objetivo: Implementar movimiento simple del jugador usando Input (acciones) y modificar la posición.
	- Captura: `godot curso/pra2.png` (hay también un duplicado `pra2'.png`)
	- Imagen: ![pra2](godot%20curso/pra2.png)

- pra3 — Variables y funciones en GDScript
	- Objetivo: Declarar variables, funciones, y control de flujo básico para la lógica del juego.
	- Captura: `godot curso/pra3.png`
	- Imagen: ![pra3](godot%20curso/pra3.png)

- pra4 — Cuerpos y colisiones
	- Objetivo: Usar KinematicBody2D/Area2D/StaticBody2D y detectar colisiones básicas.
	- Captura: `godot curso/pra4.png`
	- Imagen: ![pra4](godot%20curso/pra4.png)

- pra5 — Física: gravedad y salto
	- Objetivo: Añadir gravedad, implementar salto y resolución de colisiones con el suelo.

- pra6 — Señales (signals)
